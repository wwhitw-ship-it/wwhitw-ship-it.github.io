## 可以使用的格式

文章用 **Markdown** 撰寫，在後台編輯器裡也可以直接按按鈕排版：

- **粗體**、*斜體*、[連結](https://astro.build)
- 清單與編號清單
- 圖片（在後台直接上傳）
- 程式碼：`console.log('hi')`

> 引用文字會長這樣。

```js
function greet(name) {
  return `你好，${name}！`;
}
```
